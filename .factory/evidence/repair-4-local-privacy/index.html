Plain-language policy

Privacy

Calm Scroll keeps its extension settings in the browser’s extension storage. The sample demo stores only its sample state under a separate demo: key.

Effective 28 August 2026 · Calm Scroll v1.0.0

Extension data

The extension saves the Stable mode and exception choices for each hostname in browser-local extension storage. It does not send page text, form entries, scan counts, or browsing history to a server.

Website data

The site uses no analytics, advertising pixels, remote fonts, or runtime CDN scripts. After one online visit, the sample demo reloads offline.

Demo data

The demo does not read or write extension settings. Reset demo removes its demo:calm-scroll:sample value.

Contact

For privacy questions, open an issue in the public source repository (opens external site). Do not include page content or private information.
