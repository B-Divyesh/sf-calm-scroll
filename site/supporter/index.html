Can I read this page steadily?

Use this worksheet to record what helps on motion-heavy sites. It is a personal observation tool, not a clinical assessment.

  • Start with the page untouchedNote autoplay, drifting backgrounds, sticky layers, smooth jumps, or motion that follows the pointer.
  • Turn Stable mode onWait ten seconds. Check whether reading position, media, keyboard focus, and menus still work.
  • Try only necessary exceptionsAllow media or keep fixed/sticky layers one at a time. Record which exception restores a needed control.
  • Save the least-motion settingKeep the smallest set of exceptions that preserves the content you need.
