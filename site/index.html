Browser extension for motion-sensitive readers

Stop page motion while you read.

For people made uncomfortable by page motion, Calm Scroll pauses autoplay, animation, smooth scrolling, and sticky effects.

Install the extension in desktop Chromium.

Download the extension ZIP, unzip it, then load its folder in desktop Chromium’s Developer mode.

  1. Download and unzipSave the extension ZIP on your desktop computer.
  2. Open extensionsVisit chrome://extensions and turn on Developer mode.
  3. Load the folderChoose Load unpacked, select the unzipped folder, then pin Calm Scroll.

Know the limits.

Calm Scroll is not a medical device and does not promise a health outcome. If a site breaks, turn Stable mode off or keep the control it needs.
